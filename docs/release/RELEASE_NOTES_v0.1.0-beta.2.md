# SHINPO v0.1.0-beta.2 — Desktop Architecture & Wayland Icon Integration

Welcome to **SHINPO v0.1.0-beta.2**. This release brings automatic native desktop integration, Wayland application icon pairing, and critical browser companion registration fixes.

---

## 🚀 Key Improvements & Dev Notes

* **Wayland & Linux Desktop Icon Auto-Registration**: Automatic registration of `shinpo-desktop.desktop` and scalable hicolor icon themes on first launch, ensuring SHINPO displays its native icon across GNOME, KDE Plasma, and Wayland docks.
* **Browser Companion Host Detection**: Fixed host registration checking in desktop settings and auto-registered native manifests during desktop initialization.
* **Security & Performance**: Enhanced SQLCipher local encrypted database checkpointing and minimized idle wakeups.
