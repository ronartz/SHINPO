# SHINPO v0.1.0-beta.3 — Flat Modern Login & Cross-Platform Stability

Welcome to **SHINPO v0.1.0-beta.3**. This release removes the intrusive 3D tilt animation on authentication cards for a stable, rock-solid desktop feel, synchronizes dependency lockfiles, and improves cross-platform launch stability.

---

## 🚀 Key Improvements & Dev Notes

* **Clean Flat Login UI**: Removed the 3D mouse-tracking tilt effect on the desktop login card. The card remains completely flat, stable, and ergonomic while preserving glassmorphism accents and traveling border lights.
* **Lockfile Synchronization**: Synchronized `frontend/src-tauri/Cargo.lock` with root release specifications to guarantee clean, deterministic CI and offline compilation.
* **Auto-Registration on Launch**: Native host and application launcher configurations are automatically verified and initialized upon application startup.
