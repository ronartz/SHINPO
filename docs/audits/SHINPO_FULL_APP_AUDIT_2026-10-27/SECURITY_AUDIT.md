# SHINPO — Security Audit Report

**Audit Date:** October 26–27, 2026  
**Target:** SHINPO Full Application (Rust Core, Tauri IPC, SQLCipher Vault, Sentinel Shield, Browser Companion, Spring Boot Backend)  
**Classification:** Confidential Security Evaluation  

---

## 1. Executive Security Assessment

SHINPO demonstrates high cryptographic and defensive maturity in its native Rust components (`native_vault.rs`, `shinpo-shield`, and `shinpo-browser-host`). The encryption architecture for the local desktop vault adheres to strict zero-knowledge principles using Argon2id and SQLCipher.

However, several architectural and network security risks exist primarily at the boundaries between web mode, Tauri IPC, and development configurations:
1. **Unencrypted Loopback in Tauri CSP:** Tauri's `tauri.conf.json` explicitly permits unencrypted `http://localhost:8080` and `ws://localhost:8080`.
2. **Dual Identity & Secret Boundary:** In desktop mode, credentials are stored in SQLCipher; in web mode, authentication relies on JWT with symmetric signing.
3. **Hardcoded Fallback Secrets in Test Configs:** Default development JWT secrets are present in test property files.
4. **Wayland Process Isolation Limits:** On Linux Wayland sessions, Sentinel Shield cannot inspect window titles or surface focus without compositor-specific privileged protocols.

## 3. Cryptographic Implementation Analysis

### 3.1 Argon2id Key Derivation (`frontend/src-tauri/src/native_vault.rs`)
- **Algorithm:** Argon2id (RFC 9106 recommended).
- **Parameters:**
  - Memory cost: 65,536 KiB (64 MiB).
  - Time cost (iterations): 3 passes.
  - Parallelism: 1 lane.
  - Output key length: 32 bytes (256 bits).
  - Salt: 32 bytes securely sampled from OS CSPRNG (`getrandom` / `rand_core::OsRng`).
- **Zeroization:** The `Zeroize` and `ZeroizeOnDrop` traits are derived on all key material structures.

### 3.2 SQLCipher Database Storage
- **Encryption Scheme:** 256-bit AES-CBC (SQLCipher default) with per-page HMAC verification.
- **Key Injection:** Executed immediately after database handle opening via `PRAGMA key = "x'...'"` before any schema read or migration.
- **Integrity Validation:** `PRAGMA cipher_integrity_check;` is evaluated during unlock. Any failure returns `VaultError::CorruptDatabase` and prevents application initialization.

### 3.3 Browser Native Host Protocol (`crates/shinpo-browser-host`)
- **Protocol:** Standard Chrome/Firefox Native Messaging 32-bit little-endian length-prefixed JSON.
- **Pairing Authentication:** Employs ephemeral pairing tokens generated by desktop app, stored with single-use consumption and automatic TTL expiration.

## 4. Confirmed Vulnerabilities & Exposures

### Finding SEC-01: Tauri CSP Permits Unencrypted Loopback HTTP
- **File:** `frontend/src-tauri/tauri.conf.json`
- **Severity:** High (in multi-user systems)
- **Description:** Tauri's `security.csp` config allows `http://localhost:8080` and `ws://localhost:8080`. If another process on the user's machine binds to 8080, it could intercept unencrypted API calls.
- **Remediation:** Enforce TLS on loopback or restrict desktop builds entirely to native IPC commands (`tauri://invoke`) rather than HTTP proxies.

### Finding SEC-02: Test JWT Secret Hardcoded in Properties
- **File:** `backend/src/test/resources/application-test.properties`
- **Severity:** Medium
- **Description:** A known static string is configured for JWT secret during test runs. While excluded from production packaging, any accidental deployment with `-Dspring.profiles.active=test` would compromise authentication.
- **Remediation:** Enforce environment variable extraction with build-time failure if secret length is under 256 bits.

### Finding SEC-03: Wayland Window Focus Visibility Limitations
- **File:** `crates/shinpo-shield/src/linux.rs`
- **Severity:** Medium (Operational Security)
- **Description:** Under Wayland, unprivileged applications cannot query active window titles or active process IDs of other applications due to Wayland security models. Shield falls back to generic process enumeration via `/proc`, which can detect running applications but cannot ascertain whether an application is actively in the foreground.
- **Remediation:** Clearly document Wayland limitations in user settings; provide X11 session recommendation or optional GNOME/KDE extension bridge for active window tracking.
