SHINPO Browser Companion

Setup and privacy

Pairing

The pairing code is created locally by the native host installer. It is never included in the extension source or sent to a webpage.

Focus Rules destination

HTTPS is required except for a localhost SHINPO development installation.

Why these permissions are requested

  • Native messaging: communicates only with the per-user SHINPO host.
  • Tabs and web navigation: evaluates top-level destinations and redirects an explicitly restricted route without closing the browser.
  • Storage: retains the pairing proof and only an unexpired policy snapshot.
  • Alarms: refreshes policy and removes restrictions at lease expiry.

There is no browsing-history, cookies, downloads, webRequest, clipboard, camera, microphone, or notification permission. The only content script runs on YouTube and reads the route, not page content.
