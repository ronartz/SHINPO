### Completed product defect in this reconstruction slice

`AnalyticsService.calculateCurrentStreak` previously returned the most recent consecutive run even if its last session was several days old, while the UI labeled it a current streak. It now returns zero if the most recent completed execution day is before yesterday or after today (UTC, matching the service's existing grouping policy). Reflection cards previously rendered planned `durationMinutes` as if it were completed focus time; the API now provides `actualFocusMinutes` separately, and the UI labels active and planned time independently. The all-time completion rate is explicitly labeled and shows “No tasks yet” instead of implying 0% when its denominator is empty. `AnalyticsServiceTests` covers today, yesterday, a gap, no data, expired streak, and planned-versus-actual reflection duration: **8 passed**. User-local day boundaries remain an explicit open product requirement, not silently treated as solved.
